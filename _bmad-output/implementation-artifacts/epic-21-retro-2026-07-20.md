## 4. Difficultés & leçons (candidates durables)

1. **La remédiation crée le défaut suivant** (21-5b, 21-6b) : sur un bug d'état/course, un patch ponctuel laisse la classe ouverte. Réflexe acquis : chercher le patron qui élimine la fenêtre par construction. → codifié CLAUDE.md + memory.
2. **Distinguer défaut vs sémantique inhérente** (21-7) : la « race `as_of=Utc::now()` » d'un rapport point-in-time n'est PAS un bug (identique à l'échéancier `UTC_DATE()`). Ne pas patcher une sémantique correcte ; le paramètre reproductible = v2.
3. **La doc doit refléter le comportement réel, pas aspirationnel** (21-8) : la revue a attrapé une garantie de rétention **surévaluée** — la suppression #219 CASCADE efface l'historique de rappels. A révélé un **vrai gap produit** (#260), pas juste une imprécision doc.
4. **Flakes time-of-day** (#259) : `ManualReminderDialog` hardcode `T12:00:00` → le rappel manuel « aujourd'hui » est rejeté avant midi UTC. A fait flaker l'E2E toute la matinée. Latent depuis 21-6b, révélé par le changement de date système.
5. **Décision RBAC configurable** (#258) : le modèle 3-rôles hardcodé a suffi pour tout l'epic, mais le besoin « droits par rôle configurables » a émergé — chantier plateforme à part.
