// Roadmap

From foundations to Swiss VAT.

Kesh is delivered as a sequence of epics, each composed of small, independently reviewable stories. The release plan below tracks the path from MVP (v0.1) through sovereignty tooling (v0.2), Swiss VAT (v0.3), supplier invoices, payments & project analytics (v0.4), structured QR-bill addresses (v0.5), and invoice emailing with multilingual templates (v0.6, current) toward a feature-complete production release.

v0.1 — MVP

Foundation release

Core accounting, contacts, invoicing, banking import. The minimum a Swiss freelancer needs to issue invoices and reconcile bank statements.

E1 — Foundations & Authentication

Done

Workspace bootstrap, MariaDB schema baseline, JWT authentication with refresh tokens, password hashing, login flow.

E2 — Onboarding & Configuration

Done

Company creation flow, user-to-company assignment, multi-tenant scoping (company_id JWT claim).

E3 — Chart of Accounts & Journal Entries

Done

Swiss chart of accounts seed, double-entry validation, journal entry CRUD, immutable audit log.

E4 — Contacts & Product Catalog

Done

Contact management (customers, suppliers), product catalog with VAT rates and payment terms.

E5 — QR Bill Invoicing

Done

Invoice CRUD, QR Bill 2.2 PDF generation, invoice status workflow (draft → sent → paid).

E6 — Quality & CI/CD

Done

GitHub Actions CI pipeline, Docker images on Docker Hub, pre-commit hooks, automated release tagging.

E7 — Technical Debt Closure

Done

Multi-tenant scoping rollout, full-text search, Playwright stability fixes, security hardening (KF-002 audit).

E8 — Bank Import & Reconciliation

Done

CAMT.053 ISO 20022 parser, CSV import (multi-bank profiles), automatic reconciliation against open invoices, manual reconciliation with transaction splitting and assignment rules engine.

v0.2 – v0.3 — Sovereignty & Swiss VAT

and beyond

Growing from a working ledger toward everything an SME needs to run a full fiscal year: sovereignty tooling (v0.2), Swiss VAT (v0.3), supplier invoices, payments & project analytics (v0.4), structured addresses (v0.5), invoice emailing (v0.6), then budgets and year-end closing.

E17 — Infrastructure & Sovereignty v0.2.0

Done

External API with personal access tokens (read / read-write, per company), full installation export/import (.keshbackup) for SSH-free migration and restore, self-service password recovery by email (anti-enumeration, single-use 30-min links), atomic first-admin setup (TOCTOU fix).

E11 / E18 — Swiss VAT & VAT accounting v0.3.0

Done

Per-period VAT computation and report, multiple rates (standard, reduced, accommodation); output VAT posted automatically when sales invoices are validated; assisted entry of purchases with input VAT; VAT return (net amount due to the FTA) and reconciliation of the report against the general ledger. Official FTA e-decompte (ESTV) format planned for a later release.

E12 — Credit notes, supplier invoices & payments v0.3.2 / v0.4.0

Done

Credit notes (linked reversal of a validated invoice) — shipped in v0.3.2. Supplier invoices with binary settlement, ISO 20022 pain.001.001.09 outgoing payment file for Swiss e-banking, and folder-based supplier-invoice import with server-side Swiss QR-Bill decoding — shipped in v0.4.0.

E19 — Project cost accounting (analytics) v0.4.0

Done

An optional project dimension (two levels) taggable across every entry flow — manual journal entries (per line), sales & supplier invoices (per document), and bank reconciliation (match, split, rule default). Two exportable reports (PDF/CSV): Expenses by project (all charges, drill-down to the entry, for tax deductions) and Return by project (invested cost / revenue / net result / yield %), with sub-project roll-up and fiscal-year or cumulative views.

E20 — Invoice emailing & business email templates v0.6.0

Done

Send a validated invoice by email in one click — Swiss QR-Bill PDF attached, subject and body pre-filled in the contact's language with a personalised salutation, recipient locked to the contact card (anti-spoofing), reply-to set to your company mailbox. Admin-editable multilingual templates (FR/DE/IT/EN) with substitution variables and sensible zero-config defaults; per-contact correspondence language and salutation; full audit trail and resend support.

E13 — Budgets

Annual budgets per account, variance reports, cash-flow forecasting.

E14 — Year-end Closing

Period locking, opening balance carry-forward, closing entries automation.

E15 — Receipts, Payment Matching & Custom Journals

Document attachments, automated payment matching to invoices, user-definable journal types.
