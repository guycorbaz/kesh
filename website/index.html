Open-source Swiss accounting & invoicing

Kesh is a free, self-hosted accounting and management platform for Swiss freelancers, SMEs, and associations. QR Bill 2.2, CAMT.053 import, multi-tenant, multilingual.

View on GitHub Roadmap

Built for Swiss financial workflows

Compliance, security, and a modern stack — designed from day one for freelancers, SMEs, and accounting professionals.

Double-entry bookkeeping

Swiss chart of accounts, validated journal entries, immutable audit log.

QR Bill 2.2

Pixel-perfect Swiss QR-Bill PDF generation, fully compliant with SIX 2.2 specification.

CAMT.053 + CSV import

Bank statement import in ISO 20022 CAMT.053 format and configurable CSV profiles per bank.

Multilingual

French, German, Italian, English. Locale-aware formatting (apostrophes for thousands, dd.mm.yyyy dates).

Multi-tenant & RBAC

Strict company-level isolation, role-based access control, JWT + refresh tokens.

Self-hosted & free

EUPL 1.2 license. Docker Compose deployment. Your data stays on your infrastructure.

Modern, type-safe stack

Kesh is built on a deliberately conservative selection of modern, type-safe technologies. The accounting engine is pure Rust with comprehensive unit tests; the web layer uses Axum and SvelteKit for performance and DX.

Backend
Rust 1.96 (edition 2024), Axum, SQLx
Frontend
SvelteKit 2 + Svelte 5, TypeScript, Tailwind CSS 4
Database
MariaDB 10.11+
Deploy
Docker Compose
Testing
cargo test, Vitest, Playwright
# Quick start
git clone https://github.com/guycorbaz/kesh.git
cd kesh

# Start MariaDB + backend
docker compose -f docker-compose.dev.yml up -d

# Frontend (hot reload)
cd frontend && npm install && npm run dev

# → http://localhost:5173
